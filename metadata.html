The file is read by this page, not by a server. Nothing is uploaded or stored. Cleaning a PDF here preserves its page content; if you need to destroy underlying text as well, use the redaction page and permanently flatten it.

PDF comments are part of the file

Review notes, highlights, strikeouts, free-text comments and similar markup are PDF annotations. They can survive even when the page looks clean. Blackout lists review markup separately from links and form widgets so you can remove comments without automatically breaking navigation or forms.

“Remove everything” is deliberately aggressive

For a PDF it clears the standard document-information fields, XMP, review and other annotations, embedded files, form data, JavaScript/actions, page thumbnails and private application data that this browser tool can identify. It does not flatten the pages or rewrite visible content. For the strongest redaction workflow, clean metadata and then use permanent flattening on the redaction page.
