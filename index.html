A black box is not a redaction.

Draw a rectangle in Preview, Word, or Acrobat's markup tool and you have covered the words with a picture of a rectangle. The text is still in the file. Anyone can select it, copy it, or lift it out with one command.

This page does the work, not a server. Your file is opened by your own browser and is never transmitted anywhere. There is no upload, no account, and no copy kept. Disconnect from the internet after this page loads and it still works.

Why this one works

Most tools draw a shape on a layer above your document. That layer is cosmetic. The character data sits underneath it, untouched, and travels with the file to whoever you send it to.

This tool throws the document away. Every page is redrawn as a flat picture, your boxes are painted onto that picture, and a new file is built from the result. There is no text layer left to recover — not the parts you covered, and not the parts you didn't. Embedded metadata, annotations, tracked changes, and hidden layers go with it.

The tradeoff is real and you should know it before you rely on this: the file you get back is not searchable or selectable, and it is usually larger than the original. That is the cost of the words being genuinely gone. The longer explanation is here, and if you want to see how expensive this mistake gets, here is the record of people who got it wrong.
