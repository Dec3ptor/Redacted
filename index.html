Method:

Flattening throws the document away and keeps a picture of it, so no text survives anywhere — but neither does anything else, and the result is an image. Removing the content edits the page instead: covered words are cut out of the file, covered pixels are destroyed inside the images they belong to, and everything you did not mark is left untouched, so the rest of the document stays real, selectable text. Blackout reads the finished file back and checks it twice before offering it: nothing marked may still be there, and nothing outside your marks may have gone missing. If either check fails, nothing is saved.

Permanent means destructive

Permanent export redraws every page from pixels and paints the black areas into that image before creating the new file. The original text layer, annotations, hidden layers and document metadata are not copied into the result.

Reversible means the exact original is encrypted

Reversible mode stores the exact original file bytes in an authenticated AES-256-GCM recovery payload. That means the hidden content can be text, a photograph, a diagram, vector artwork, or an image embedded in a PDF — Blackout does not have to reconstruct it later. The generated BO2 recovery key contains 256 random bits and is the recommended mode. Custom passphrases are supported but are only as strong as the passphrase itself.

Redaction now flows into metadata removal

Continue sends the newly redacted file directly to the metadata stage using local browser storage. Nothing is uploaded. The final save happens after metadata removal and the Blackout branding mark is applied.

Smart scan is intentionally conservative

The offline smart scan looks for patterns such as email addresses, phone numbers, payment-card-like strings, bank-account-like numbers, IP addresses, IBANs and coordinate pairs. It does not pretend to understand names or street addresses reliably. Review every box before saving.
